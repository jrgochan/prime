\begin{abstract}
We describe a Lean~4 formalization---the \emph{Cathedral}---that reduces
the Riemann Hypothesis to the decay rate of a single quadratic form
built from M\"obius values and Vasyunin cotangent sums.

No integrals. No complex plane. No analytic continuation. No measure theory.

The formalization compiles with \textbf{zero errors} and \textbf{zero sorry}.
The single axiom encoding RH is
$1 - 2b^Tv + v^TG_Nv \leq C/\ln N$,
where $v$ is the log-cutoff M\"obius witness and $G_N$ is the
integral-based Gram matrix. This axiom is \textbf{machine-verified to be
exactly equivalent to RH}.

In plain English: \emph{the $L^2$ approximation error of the Selberg-weighted
M\"obius function decays at rate $1/\ln N$.}
\end{abstract}

\section{What Did We Do?}

We used a computer proof assistant called \textbf{Lean~4} to reduce the
167-year-old Riemann Hypothesis to a single, concrete, finite statement
about weighted M\"obius sums over cotangent values.

\textbf{We did not prove RH.} We built a \emph{machine-verified framework}
that identifies exactly which mathematical facts remain to be established,
proves everything else with compiler-checked rigor, and reduces the entire
problem to a finite, computable quantity.

\section{The Discrete Vasyunin Reduction}

\subsection{The Gram Matrix (No Integrals)}

The Vasyunin formula gives the exact inner products of the B\'aez-Duarte
basis $h_k(x) = \{1/(kx)\}$ in $L^2(0,1)$ as a \emph{finite sum}:
\[
G(j,k) = \frac{\ln(2\pi) - \gamma}{2}\left(\frac{1}{j}+\frac{1}{k}\right)
  + \frac{j-k}{2jk}\ln\frac{k}{j}
  - \frac{\pi d}{2jk}\bigl(V(j',k') + V(k',j')\bigr)
  - \frac{1}{jk}
\]
where $d = \gcd(j,k)$, $j'=j/d$, $k'=k/d$, and the Vasyunin sum is
$V(a,b) = \sum_{m=1}^{a-1} \{mb/a\} \cot(\pi m/a)$.

This formula involves only: $\gcd$, $\log$, $\cot$, and fractional parts.
\textbf{No integrals appear anywhere.}

\subsection{The Augmented Gram Matrix}

The key architectural insight is the \emph{augmented Gram matrix}:
\[
H_N = \begin{pmatrix} 1 & b^T \\ b & G_N \end{pmatrix}
\]
This is the Gram matrix of $\{1, f_1, \ldots, f_N\}$ in $L^2(0,1)$,
where $f_k(x) = \{1/(kx)\}$ are the B\'aez-Duarte fractional-part functions.

By evaluating these functions on the highly divisible interval
$(1/(N!+1),\; 1/N!)$ (the ``Factorial Nuke''), we establish
unconditionally that no nontrivial augmented linear combination
vanishes on $(0,1)$, providing a \textbf{direct, non-inductive proof}
that $H_N$ is positive definite for all $N \geq 1$. This yields:
\begin{itemize}
\item $G_N$ PD (trailing submatrix embedding $w = (0, x)$)
\item $b^T G_N^{-1} b < 1$ (witness vector $w = (1, -G_N^{-1}b)$)
\item $C_N = G_N - bb^T$ PD (Schur complement)
\end{itemize}

\subsection{The Log Cutoff Witness}

The explicit witness vector
\[
v_k = -\mu(k)\left(1 - \frac{\ln k}{\ln N}\right)
\]
defines a Rayleigh quotient $Q_N = (b^T v)^2 / (v^T C_N v)$ that provides
a \emph{constructive lower bound} on $X_N = b^T C_N^{-1} b$ via the
variational principle. Experimentally (Attack~9, to $N=50{,}000$):
