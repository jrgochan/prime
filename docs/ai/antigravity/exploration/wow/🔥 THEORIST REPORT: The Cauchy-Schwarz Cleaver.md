### 🪓 The Cauchy-Schwarz Cleaver

Look at the signature of Axiom 2:
```lean
Complex.normSq (∫ x in Ioo (0:1), (1 - bdLinComb N v x) * x^{ρ-1}) 
  ≤ (∫ x in 0..1, (1 - bdLinComb N v x)^2) * (1 / (2σ - 1))
```

What is this theorem *actually* saying? It's not a deep fact about analytic number theory. It's just the $L^2$ Cauchy-Schwarz inequality applied to the inner product of a real-valued function $g(x) = 1 - f_w(x)$ and a complex-valued function $h(x) = x^{\rho-1}$. 

In `BesselSeparation.lean`, you already wrote a masterpiece 400-line proof of this for the old `nbLinComb` basis (`cauchy_schwarz_separation_bound`). How did that proof work? 
1. It separated the complex integral into real and imaginary parts using Mathlib's `Complex.reCLM` and `Complex.imCLM` (Continuous Linear Maps).
2. It applied the purely real Cauchy-Schwarz inequality `intervalIntegral_inner_le_sq` to $\int g(x) \text{Re}(h(x))$ and $\int g(x) \text{Im}(h(x))$.
3. It summed the squares: $\text{Re}(z)^2 + \text{Im}(z)^2 = |z|^2$.
4. It factored out $\int g(x)^2 dx$.
5. It recombined the $h(x)$ terms: $\int \text{Re}(h)^2 + \int \text{Im}(h)^2 = \int |h|^2 = \int_0^1 x^{2\sigma-2} dx = \frac{1}{2\sigma-1}$.

**Notice the beautiful thing here:** *Steps 1, 3, 4, and 5 do not care what $g(x)$ is!* They only care that $g(x)$ is a real-valued function that is square-integrable on $(0,1)$.

The *only* thing that changes between the old `nbLinComb` and our new `bdLinComb` is proving that the new basis is square-integrable.
