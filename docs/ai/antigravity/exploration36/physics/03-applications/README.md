# Layer 3: Applications

## Cross-Domain Predictions from the Cathedral Framework

This layer applies the three structural insights (Percolation, Ward, Projection) across science and technology. Each prediction is grounded in proved theorems from the Cathedral Physics Engine and is specific enough to be tested.

### Documents

- [**Technology Proposals**](technology.md) — Three concrete engineering applications with near-term feasibility: phononic metamaterials, Ward Decomposition Analysis (WDA), and arithmetic cryptographic primitives.

- [**Scientific Predictions**](scientific-predictions.md) — Domain-by-domain analysis of what the Cathedral framework predicts in biology, neuroscience, ecology, cosmology, economics, and more. Organized by domain with testability ratings.

- [**Cross-Domain Summary**](cross-domain-table.md) — A single-page reference table mapping all predictions across all domains. Quick scan of the full landscape.

### Confidence Levels

Not all applications carry equal weight. They range from:

**High confidence** (direct consequence of proved theorems):
- Ward decomposition of any bilinear form
- Projection of any signal through a binary filter
- Spectral gap positivity for linearly independent basis systems

**Medium confidence** (structural analogy with proved backbone):
- Ward Health Index discriminating system states
- Phononic band gaps from arithmetic lattice designs
- WDA outperforming PCA for parity-structured data

**Speculative** (the insight suggests but does not prove):
- 6/π² appearing as a universal threshold in natural systems
- Dark matter fraction related to 1 − 6/π²
- Baryon asymmetry as a cosmological Ward current

### How to Read This Layer

If you're an **experimentalist**: start with [Scientific Predictions](scientific-predictions.md) and look for your domain. Each prediction comes with the exact data source and computation procedure needed to test it.

If you're an **engineer**: start with [Technology Proposals](technology.md). The three proposals are ordered from most speculative (metamaterials) to most immediately implementable (WDA library).

If you want a **quick overview**: the [Cross-Domain Table](cross-domain-table.md) fits the entire landscape on one page.
