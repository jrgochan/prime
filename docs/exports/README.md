# Cathedral Source Exports

These are **historical snapshots** of the Cathedral Lean source, captured at
various stages of development for AI context and cross-referencing.

They are **not maintained** and may reference outdated axiom counts, old
constant values, or superseded architecture. For the current state, see
[OVERVIEW.md](/OVERVIEW.md) at the repository root.

## Directories

- `full/` — Complete source dumps (01–09, chronological)
- `critical-path/` — Crown path files only
- `archive/` — Older dump formats

## Generation

These were generated by `scripts/cathedral_dump.py`. To create a fresh
export of the current Cathedral:

```bash
make dump
```
